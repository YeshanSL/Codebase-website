// faq

Frequently asked questions

What services does CODE BASE provide?

Website development, custom software, web applications, UI/UX design, branding, and digital solutions such as dashboards and integrations.

How much does a website or software project cost?

It depends on scope, features, and timeline. After reviewing your requirements we send a clear quotation before any work begins.

How long does a project take?

Timelines vary by project. We agree a timeline with you during the planning stage.

Can CODE BASE develop custom software?

Yes. We build tailored business systems and workflow automation shaped around your requirements.

Do you provide website maintenance?

Yes, as agreed. Support and maintenance scope is defined up front rather than promised as unlimited by default.

Can project requirements be changed during development?

Changes can be discussed at any point. Larger changes may affect timeline or cost, and we agree them with you first.

Do you work with clients outside Sri Lanka?

Yes. Projects can be planned and delivered remotely, so we can work with clients internationally.
